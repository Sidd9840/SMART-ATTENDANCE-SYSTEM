📘 About Smart Attendance System

Smart Attendance System is a secure web-based attendance management application developed for educational institutions. The system uses Geo-Fencing technology to verify the student's location before allowing attendance. It helps prevent proxy attendance, saves teachers' time, and provides accurate attendance records. The application provides separate modules for Admin, Teacher and Student users.
